# AgentProof 기술보고서 — 작성 틀

상태: 개별 연구 파트를 작성 중입니다. 아래 목차는 전체 프로젝트의 완료를 뜻하지 않습니다.

## 1. 문제와 연구 범위
다루는 에이전트·개입·연구 질문과 범위를 작성합니다.

## 2. 공통 실험 방법
[공통 규칙](../docs/EXPERIMENT_PROTOCOL.md)을 바탕으로 실제 사용한 태스크·채점·반복·비용 측정 방법을 기술합니다.

## 3. 개별 연구
검토를 마친 실험 카드와 결과 commit을 연결하고 설계·관찰·한계를 요약합니다.
E00 모의 예시는 연구 결과에 포함하지 않습니다.

- [E02 · 스킬 적용 전 확인과 완료 전 검증](e02-skill-precheck.md): 기존 파일럿 재검토와 보강 통제 실험. 공개 과제 확증·교차 재현과 구분합니다.

## 4. 연구 간 종합
벤치마크 점수를 합산하지 않고 효과가 나타난 조건·실패 양상·비용 관계를 종합합니다.

## 5. 교차 재현
독립 실행의 조건·결과·차이를 기록합니다.

## 6. 한계와 재현 안내
일반화의 범위·미확인 사항·실행 절차를 명시합니다.
