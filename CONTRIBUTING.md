# Contributing to AgentProof

## Weekly GitHub rhythm

Every Runner, every week, must land **at least one** of:
- code / config change
- Experiment Card update
- result log / analysis note
- decision or blocker write-up

Prefer a small PR that can be reviewed and merged within the week.

## PR checklist

- [ ] Clear title: `[Wxx] <topic>`
- [ ] Links Research Question or Experiment Card path
- [ ] Metrics fields filled when reporting results (success, reliability, token, cost)
- [ ] Negative / null results included when relevant

## Branch & folders

- `experiments/<runner-id>/` — personal experiments & cards
- `harness/` — shared evaluation code (when added)
- `templates/` — copy, don't edit the example in place for personal work

See also: [`docs/SUCCESS_CRITERIA.md`](docs/SUCCESS_CRITERIA.md), [`docs/ROLES.md`](docs/ROLES.md).
