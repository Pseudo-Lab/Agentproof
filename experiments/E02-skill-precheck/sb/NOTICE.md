# SkillsBench 사용 고지

이 폴더의 과제 선정·스킬 변형(`tasks.json`)과 `skills/graph`, `skills/csv`의 발췌는 SkillsBench(benchflow-ai/skillsbench, commit `f860ecf02ef53412a030f8661c83d644b739ff01`, Apache License 2.0, 라이선스 사본은 `LICENSE-SkillsBench`)의 과제·스킬을 바탕으로 한다. 과제 환경·oracle·verifier는 원본 저장소에서 직접 받아 수정 없이 쓰며 이 레포에 복사하지 않는다. 바꾼 내용은 `tasks.json`의 `skill_edits_E1`·`s_section`에 전부 적혀 있다.

인용: SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks, arXiv:2602.12670.
