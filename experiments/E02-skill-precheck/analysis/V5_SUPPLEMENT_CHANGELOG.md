# 2026-11-10 사후 보충 분석

사용자의 추가 검토 요청으로 이미 완료된 v5 180 trial을 다시 분석했다. 모델 API는 호출하지 않았다. 당시의 protocol, raw trials, manifest, frozen code_snapshot과 주요 분석 JSON은 변경하지 않았다.

추가한 내용:

1. 동일한 과제·입력의 C2/N 15쌍을 맞춘 불일치 성공 수와 양측 정확 McNemar 민감도 검사. 고정 입력 쌍에 대한 가정부 분석이며 과제군 일반화 검정이 아니다.
2. 과제군 하나씩 제외한 평균 차이. graph를 제외하면 +20%p가 −10%p로 바뀌는 과제 의존성을 명시했다.
3. 모든 N/C2/V/P의 사후 도구 호출 집계, 특히 V/P 60 trial의 사후 Python 15개 코드·반환을 전수 검토했다. 호출 횟수, 행동이 나온 trial 수, 실제 산출물 변화는 구분했다.
4. E0의 0~0 부트스트랩 구간이 관찰하지 못한 실패 위험을 반영하지 못한다는 주의를 추가했다.
5. 렌더러에서 빠졌던 과제별 전이 표를 부록으로 추가했다. 원 분석 JSON의 기존 과제별 필드를 사용했으며 수치를 새로 만든 것이 아니다.
6. 새 보충 분석의 정확 계산·짝 누락 및 중복 거부·과제 제외 민감도 테스트 4개를 추가했다.

보충 코드: src/sensitivity_v5.py. 원자료: analysis/v5_sensitivity.json. 사람의 코드 전수 검토: analysis/V5_POST_PYTHON_REVIEW.md. 보고서: report/e02-skill-precheck.md(레포 루트 기준).

독립 방법론 검토 후, 마지막으로 산출물 열람 지표의 이름을 산출물 read_file로 명확히 했다. Python을 통한 산출물 읽기는 별도 코드 검토·Python 실행 열에 포함되고, read_file 열의 횟수에는 합치지 않았다.
