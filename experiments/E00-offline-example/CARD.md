# E00 — 오프라인 파일럿 PR 연습

> **MOCK / 제출 형식 연습 전용.** 사람이 지정한 응답을 채점한 결과이며 모델·개입 효과의 연구 근거가 아닙니다.

## 신원과 상태
- 실험 ID: E00 (예약된 예시 ID)
- 작성자: AgentProof 제출 키트 예시
- 단계: 모의 파일럿 완료 / 실제 연구 미실시
- 실행 모드: mock (`mock-fixed-responses-v1`)
- 실행 시각·코드 commit: `results/pilot/example-001/manifest.json` 참조
- 코드 상태: 제출 키트 작성 중 실행하여 `code_dirty=true`. base commit만으로 이 코드를 재현할 수 없으며 이 예시를 포함한 변경본이 필요합니다.

## 연습 질문

3개 태스크를 두 조건에서 반복 채점하고 실패·미측정 값을 포함해 로그와 요약을 만들 수 있는가?
실제 연구 가설은 없습니다. 조건별 고정 응답 차이는 테스트용 fixture입니다.

## 비교 설계
- 데이터: `data/tasks.json`, 공개 산술 문제 3개. 파일 SHA-256은 manifest에 기록.
- Baseline / Intervention: `configs/baseline.json`, `configs/intervention.json`.
- 조건 차이: T02 고정 응답을 `20`에서 `14`로 바꿉니다. 실제 Skill이나 프롬프트 개입은 없습니다.
- 고정 조건: 같은 태스크·정답·문자열 채점기, 태스크당 조건별 5회.
- 개입 적용 확인: trial의 `evidence.config`, `response`와 manifest의 설정 전문.
- 채점: 앞뒤 공백 제거 후 문자열 일치. 숫자 표현의 동치 판정은 하지 않습니다.
- 실행 순서: 조건 → 태스크 → 반복. seed·sampling·재시도 없음.
- 예산: 외부 API 호출 없음. 실제 모델 실행 예산은 정하지 않았습니다.

## 모의 파일럿 관찰

| 항목 | Baseline | Intervention |
| --- | --- | --- |
| 태스크 수 × 반복 | 3 × 5 | 3 × 5 |
| 성공 수 / 모든 시도 수 | 5 / 15 | 10 / 15 |
| 성공률 | 33.3% | 66.7% |
| 모든 반복 성공 태스크 / 전체 태스크 | 1 / 3 | 2 / 3 |
| 오류 / timeout | 0 / 0 | 0 / 0 |
| 토큰·비용 | null (모델 호출 없음) | null (모델 호출 없음) |

로컬 채점 시간은 summary에 있습니다. 모델 latency로 해석하지 않습니다.
고정 응답을 반복한 것이므로 반복 안정성 수치는 실제 모델 reliability를 나타내지 않습니다.

## 설계 변경과 최종 태스크

형식 연습이므로 태스크 변경 없음. 실제 연구의 최종 태스크·모델·개입·예산은 미확정입니다.
Runner는 이를 자신의 질문에 맞게 교체한 뒤 실제 파일럿을 실행해야 합니다.

## 해석과 한계

30개의 모의 행을 저장하고 공통 집계기로 다시 요약할 수 있습니다.
성공률 차이는 설정한 응답을 그대로 반영합니다. 태스크 난이도·개입 효과·통계적 유의성·실제 비용에 대한 주장은 할 수 없습니다.

## 교차 재현

미실시. 다른 참여자가 명령을 실행하면 제출 형식의 재현 연습은 가능하지만 실제 연구의 교차 재현으로 세지 않습니다.
