# 파일럿 PR 본문 작성 예시

아래는 E00 **모의 실행**을 대상으로 작성한 예시입니다. 실제 파일럿 PR에서는 실험 ID·설계·관측값·경로를 모두 내 것으로 바꾸세요.
모의 성공률을 실제 연구 결과로 사용하지 마세요.

제목: `[E00][pilot] 오프라인 채점·로그 제출 연습`

---

## 실험과 단계

- 실험 ID / 제목: E00 / 오프라인 파일럿 PR 연습
- 단계: pilot (mock)
- Experiment Card: `experiments/E00-offline-example/CARD.md`

## 무엇을 검증하나요?

고정 응답으로 태스크 × 조건 × 반복 로그를 저장하고 요약할 수 있는지 확인합니다.
3개 산술 태스크, 동일 문자열 채점기를 사용합니다.
T02의 설정된 응답만 baseline `20`, intervention `14`로 다릅니다. 모델·Skill 개입은 없습니다.

## 관찰 결과

- 3개 태스크 × 조건별 5회, 총 30개 모의 시도
- baseline 5/15 성공, intervention 10/15 성공
- 모든 반복 성공 태스크: baseline 1/3, intervention 2/3
- 토큰·비용: null (모델 호출 없음)
- 시간: `summary.json`의 로컬 채점 시간, 실제 모델 응답 시간이 아님
- 로그: `experiments/E00-offline-example/results/pilot/example-001/`

## 파일럿 이후 변경과 최종 설계

형식 연습이므로 변경 없음. 실제 연구의 태스크·개입·예산은 아직 정하지 않았습니다.
개입의 효과에 대한 결론은 내리지 않습니다.

## 확인 방법

레포 루트에서 실행합니다. API 키·외부 패키지는 필요 없습니다.

```sh
python3 harness/summarize.py experiments/E00-offline-example/results/pilot/example-001
```

수동 점검: T01은 두 조건 모두 정답, T02는 baseline만 오답, T03은 두 조건 모두 오답입니다.
모의 설정 적용과 채점 근거는 각 trial의 `evidence`를 확인할 수 있습니다.

## 한계와 도움이 필요한 부분

고정 응답을 반복하므로 실제 모델 성능·안정성·비용을 알 수 없습니다.
실제 연구에서는 태스크·실행기·채점기를 교체하고 개입 적용 증거를 추가해야 합니다.
