| Evaluation & Metrics | success/reliability/cost 계측 | ✅ |
| Data / Log Analysis | 결과 표·시각화·해석 | ✅ |

| Documentation & Presentation | Card, Board, 발표 | ✅ |
| Open-source Release | README, 라이선스, 릴리스 노트 | ✅ Builder와 함께 |
